## Free deployment

The site is static and can be hosted with GitHub Pages.

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and your `resume.pdf`.
3. In repository Settings → Pages, enable deployment from the main branch.
4. Use the generated GitHub Pages URL on your CV.

No server or paid hosting is required.
